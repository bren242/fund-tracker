# test-data/

תיקייה לקבצי דוחות לבדיקת רגרסיה של ה-parser.

## שימוש

הוסף לכאן 2-3 קבצי דוחות מייצגים:
- לפחות אחד בשקלים (ILS)
- לפחות אחד בדולרים (USD)
- רצוי אחד עם נתונים חלקיים / שנים חסרות

## פורמטים נתמכים

`.pdf` / `.png` / `.jpg`

## הפעלת בדיקה

```
POST /api/parse
Content-Type: multipart/form-data
Body: { file: <file> }
```

תוצאות נרשמות ב-`test-results.md` (לא נשמר ב-repo).
